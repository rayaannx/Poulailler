POULAILLER - VERSION GITHUB + SUPABASE

Mettre tous les fichiers à la racine du dépôt GitHub puis activer GitHub Pages.
La table public.series et ses politiques sont dans supabase/schema.sql.
Dans Supabase Auth > Email, active Email. Si nécessaire, désactive Confirm email pour tester comme dans ton projet actuel.
La clé dans js/config.js est la clé publishable. Ne jamais mettre une clé secret/service_role dans GitHub.
Le Dark Mode est sauvegardé dans le navigateur.
